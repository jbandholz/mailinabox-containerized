# Chunk 17 — CI Pipeline & Release Metadata

**Goal:** registry-neutral CI that builds, tests, scans, and optionally publishes signed
releases — the supply chain behind `miab-update`.

**Depends on:** 07, 13 (integration stages benefit from 14–16 as gates)
**Read first:** `../shared-context.md` + this file.
**Optional deep-dive (megaplan):** §CI, Image Publication, and Supply Chain; Impl. step 13; Acceptance #10.

## Scope

### `.github/workflows/container.yml` (or repo's CI equivalent)

Stages, all actions pinned by immutable revision:

1. Shell lint (`bash -n`, ShellCheck) + Ruff + Python unit tests (incl. `tests/container/`).
2. Config render tests: IPv4-only + dual-stack generations.
3. `linux/amd64` image build (no push) from locked inputs.
4. Image inspection gate: no secrets/instance state/package caches; labels correct;
   package/asset versions match locks.
5. Vulnerability scan with documented severity policy + exceptions process.
6. SBOM + provenance generation.
7. Container smoke test inside a podman `miab-test-host` job container — firewall
   application disabled so CI cannot touch the runner host.
8. Kustomize render + schema validation.
9. Release-manifest generation + verification against embedded image labels and
   current/one-back migration test results.
10. Optional publish: sign + push digest, manifest, SBOM, provenance — only when
    registry/update-source credentials are configured; refuse on any failed gate.

## Rules

- Never weaken package-manager minimum-age/security settings to make builds pass.
- The signed release manifest — not an image tag — is the update channel's truth.
- Integration tests in CI are synthetic and run inside the podman `miab-test-host`
  harness (stubbed peers, nested k3s); real DNS/mail/firewall/public-infrastructure
  testing is exclusively chunk 18.

## Verification

- [ ] Pipeline green on a candidate commit; each gate demonstrably fails on a seeded fault
      (bad signature, label mismatch, missing lock, unclassified setup module).
- [ ] Published artifacts (dry-run registry) consumable by `miab-update check/plan`.
- [ ] Reproducibility comparison job reports explained variance only.
